# Cube Trainer

*A Computer Vision Project for CS 566*

**Repository:** [github.com/ntsai04/cubetrainer](https://github.com/ntsai04/cubetrainer/tree/main)

**Demo Video:** [Cube Trainer Demo](https://youtu.be/JU1_JgLlKKM)

### Installation & Running

1. **Clone the repository**
   ```bash
   git clone https://github.com/ntsai04/cubetrainer.git
   cd cubetrainer
   ```

2. **Install dependencies**
   ```bash
   pip install opencv-python numpy
   ```

3. **Run the program**
   ```bash
   python run.py
   ```

### Controls
- **Spacebar** - Capture the currently detected face colors
- **R** - Reset captured cube faces
- **Q** - Quit the program

### Usage
- Capture yellow face first
- Capture adjacent remaining faces in any order/orientation
- Follow algorithm with yellow side up and green side facing you
